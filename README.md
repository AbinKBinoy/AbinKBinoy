## Current project

**[ShiftSync](https://github.com/AbinKBinoy/shiftsync)** — AI-powered shift scheduling. Upload a photo of a posted schedule, Claude Vision reads every shift automatically, your team joins with a code and manages swaps from there.

- Live: [shiftsync.win](https://shiftsync.win)
- Frontend: Next.js, TypeScript, Tailwind, Supabase
- [Extraction service](https://github.com/AbinKBinoy/shiftsync-extraction): Python, FastAPI, Claude Vision API
